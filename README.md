
# 세계 데이터 지도 (Interactive World Data Map)

**세계 데이터 지도**는 인구, 면적, 지니 계수 등 다양한 국가별 통계 데이터를 시각화하는 대화형 코로플레스(Choropleth) 지도 애플리케이션입니다. D3.js를 사용하여 데이터를 동적으로 시각화하고, Google Gemini API를 통합하여 AI 기반의 심층적인 데이터 분석 및 지도 제어 기능을 제공합니다.

라이브 데모 : https://sigco3111.github.io/world-data-map/

[![Live Demo](https://img.shields.io/badge/Live%20Demo-181717?style=for-the-badge&logo=github&logoColor=white)](https://sigco3111.github.io/world-data-map/)

---

## 주요 기능

*   **🗺️ 대화형 세계 지도**: 지도를 자유롭게 이동(Pan)하고 확대/축소(Zoom)하며 전 세계를 탐색할 수 있습니다.
*   **📊 동적 데이터 시각화**: '인구', '면적', '지니계수' 등 원하는 지표를 선택하면, 지도 색상이 해당 데이터에 따라 동적으로 변경됩니다.
*   **⚖️ 다중 스케일 지원**: 선형(Linear) 및 로그(Log) 스케일을 선택하여 데이터 분포에 따른 최적의 시각화를 경험할 수 있습니다.
*   **ℹ️ 상세 국가 정보**: 국가를 클릭하면 수도, 인구, 면적, 소속 지역, 통화, 언어 등 상세 정보를 오른쪽 패널에서 확인할 수 있습니다.
*   **🆚 국가 비교 모드**: 최대 4개의 국가를 선택하여 주요 지표(인구, 면적 등)를 막대그래프로 한눈에 비교할 수 있습니다.
*   **🤖 Gemini AI 통합 (선택 기능)**:
    *   **AI 비교 분석**: 선택된 국가들의 경제, 문화, 지리적 특징을 AI가 비교 분석하여 흥미로운 사실들을 요약해줍니다.
    *   **최신 정보 검색**: 특정 국가의 최신 뉴스나 주요 사건을 Google 검색을 통해 찾아 요약된 정보를 제공합니다.
    *   **챗봇 기반 지도 제어**: "아프리카 대륙으로 확대해줘" 또는 "인구가 가장 많은 5개국을 보여줘" 와 같은 자연어 명령으로 지도를 제어하고 정보를 얻을 수 있습니다.
*   **🔑 사용자 API 키 지원**: 사용자는 자신의 Gemini API 키를 입력하여 AI 기능을 활성화할 수 있습니다. API 키는 브라우저의 로컬 스토리지에 안전하게 저장됩니다.

## 기술 스택

*   **프레임워크**: React (with TypeScript)
*   **데이터 시각화**: D3.js
*   **AI 모델**: Google Gemini API (`@google/genai`)
*   **스타일링**: Tailwind CSS
*   **지도 데이터**: TopoJSON (from `world-atlas`)
*   **국가 통계**: [REST Countries API](https://restcountries.com/)
*   **모듈 로딩**: `esm.sh`를 이용한 브라우저 기반 모듈 임포트 (별도의 빌드 과정 불필요)

## 시작하기

이 애플리케이션은 별도의 빌드나 설치 과정 없이 브라우저에서 바로 실행할 수 있습니다.

### 사전 준비물

1.  최신 웹 브라우저 (Chrome, Firefox, Safari, Edge 등)
2.  (선택 사항) AI 기능을 사용하기 위한 [Google Gemini API 키](https://aistudio.google.com/app/apikey)

### 설정 및 실행 방법

1.  이 프로젝트의 `index.html` 파일을 웹 브라우저에서 엽니다.
2.  **AI 기능 활성화 (선택 사항)**:
    *   화면 상단의 `API Key` 입력란에 자신의 Gemini API 키를 붙여넣습니다.
    *   `저장` 버튼을 클릭합니다. 키가 유효하면 API 상태 아이콘이 노란색(대기)에서 초록색(활성화)으로 바뀝니다.
    *   `Gemini API` 토글 스위치를 켜서 AI 관련 기능을 활성화합니다.

### 사용 가이드

*   **지도 탐색**: 마우스로 지도를 클릭 후 드래그하여 이동하고, 마우스 휠을 사용하여 확대/축소합니다.
*   **데이터 지표 변경**: 상단의 '지표'와 '스케일' 컨트롤을 사용하여 지도에 시각화할 데이터를 변경합니다.
*   **국가 정보 보기**: 원하는 국가를 클릭하면 오른쪽 정보 패널에 상세 데이터가 표시됩니다.
*   **국가 비교하기**:
    1. '국가 비교' 토글을 켭니다.
    2. 지도에서 비교하고 싶은 국가들을 클릭하여 선택합니다 (최대 4개).
    3. Gemini API 토글이 켜져 있다면, `AI로 비교 분석하기` 버튼을 눌러 AI의 심층 분석을 받아볼 수 있습니다.
*   **AI 챗봇 사용하기**:
    1. Gemini API 토글을 켭니다.
    2. 오른쪽 패널 하단의 채팅창에 원하는 명령을 입력합니다.
    3. **예시 명령어**:
        *   `유럽으로 확대해줘`
        *   `브라질과 아르헨티나를 강조해줘`
        *   `지도 초기화`
        *   `지표를 면적으로 변경해줘`
        *   `캐나다의 최신 소식 알려줘`
